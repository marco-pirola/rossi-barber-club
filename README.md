# Rossi Barber Club

A premium responsive website for a fictional barber shop based in Bergamo, Italy.

## 🌐 Live Demo

[Visit the live website](https://marco-pirola.github.io/rossi-barber-club/)

## ✂️ About the Project

Rossi Barber Club is a modern barber shop website designed and developed from scratch.

The project focuses on creating a premium digital presence for a barber shop, combining an elegant visual identity with a responsive and accessible user experience.

## ✨ Features

- Responsive design
- Desktop and mobile navigation
- Mobile hamburger menu
- Smooth scrolling
- Active navigation state
- Service section
- Interactive FAQ
- Booking request form
- Form validation
- Toast notifications
- Scroll reveal animations
- Accessibility-focused HTML
- Reduced motion support
- Responsive layouts for desktop, tablet and mobile

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
